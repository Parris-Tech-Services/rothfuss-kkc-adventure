# Canon guard (DRAFT, constraints only)

This project adapts another author's world. The rule set here is deliberately the opposite of the other repos' "invent more" program.

1. **No invention.** Do not add characters, places, lore, names or events that are not in the source material or in Josh's approved design docs. No name generator, no model-chosen names.
2. **Lore guard.** Any new text that states a fact about the world must cite where the fact comes from (source book or approved design doc). If it cannot, it is not written.
3. **No reproduction.** Do not paste or closely paraphrase passages from the books. Game text is original wording about canon facts.
4. **Keep it private.** Fan adaptations of a living author's work should not sit in a public repository or be hosted publicly without the owner's decision on rights.

## Audit (2026-11-13)
No third-party documents are tracked in this repository. Its sibling `kkc-adventure` does have some; see that repo's `docs/CANON-GUARD.md`.
